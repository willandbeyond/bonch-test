Private notes import

This tool runs only on the Cloudflare development site. Notes are sent directly to the authenticated Worker and stored in D1; they are not committed to GitHub. Import replaces notes for matching trip indices only.

Paste a JSON object containing a notes array. Each item needs trip_key (zero-based trip index, 0–43) and note. Example:

{"notes":[{"trip_key":"0","note":"My private note"}]}
